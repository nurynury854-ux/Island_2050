# Citizen photos

Put your photos here. The game picks them up automatically, no code changes needed.

Name each file `<id>-<mood>.jpg`:

| id | persona |
|---|---|
| advisor | Chief Advisor (narrator) |
| ahhai | Ah-Hai, fisherman |
| mei | Mei, university student |
| wei | Wei, factory worker |
| lin | Grandma Lin, rice farmer |
| kai | Kai, chip engineer |

Moods: `happy`, `neutral`, `angry`

Example: `mei-happy.jpg`, `mei-neutral.jpg`, `mei-angry.jpg`

Tips: square crop (e.g. 600×600), face centered, plain background. Keep each file under ~200 KB.
If a photo is missing, an illustrated placeholder is shown instead.

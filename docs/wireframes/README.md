# Wireframes

Low-fidelity wireframes of every page, made for the Nov 27 progress slides.

| File | What it is |
|---|---|
| `index.html` | All wireframes in one page. Open it in a browser. Add `?only=home` (or `sitemap`, `setup`, `game`, `turn`, `results`, `learn`, `sdgs`, `hall`, `about`) to see just one. |
| `png/` | One 3200×1800 (16:9) image per page, ready to drop into slides |
| `render.sh` | Regenerates the PNGs with headless Chrome: `bash docs/wireframes/render.sh` |

**How to read them:** gray solid boxes are built; **coral dashed** boxes are planned. Numbered markers match the notes on the right.
Numbers in the wireframes (budget, scores, player stats) are examples, not real results.

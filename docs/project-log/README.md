# Project Log

This folder records how the project was built: planning, progress, decisions, difficulties and
data sources. It's the raw material for the presentation slides (the proposal demo and the final).

| File | What goes in it | Useful for slides about… |
|---|---|---|
| [devlog.md](devlog.md) | Dated entries: what was done each session, what's next | Progress, "how far along are we" |
| [decisions.md](decisions.md) | Every important choice, the alternatives, and why | Planning, design reasoning |
| [challenges.md](challenges.md) | Problems hit and how they were solved | "Difficulties we faced" |
| [sources.md](sources.md) | Where data/facts come from, how game numbers were chosen, credits, AI usage | Relevance to SDGs, honesty/credits |

**How to keep it up to date:** after each work session, add a devlog entry. When something important
is decided, add it to decisions.md. When something goes wrong, write it in challenges.md, even if
it's still unsolved.

The master plan is in [../PLAN.md](../PLAN.md).
